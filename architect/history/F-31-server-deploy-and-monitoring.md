# F-31 design history

- **v0.1 (31 Oct 2026):** both services on the host network (ADR-034 first version). `serve` was on `127.0.0.1:8080`, with no Go change. Caddy bound ports through the host-wide unprivileged-port sysctl, and its admin API was on a Unix socket in `/srv/caddy`.
- **v0.2 (1 Nov 2026):** user decision, no host networking. Added `edge` and `backend` bridge networks, the `WORKOUT_EXPLORER_TRUSTED_PROXY` setting (ADR-021 rev. 5), DP-1a and DP-1b (Docker daemon settings for real source addresses), the `conntrack` check, and the admin API on `localhost` inside the Caddy container.
- **v0.3 (1 Nov 2026):** user decisions (decision log 1 Nov 2026, both entries). Caddy behind the operator's reverse proxy on a plain HTTP port bound to `127.0.0.1`; dropped automatic HTTPS and ACME without e-mail, ports 80/443 and 443/udp, `/srv/caddy` (certificates, ACME account), IPv6 on `edge`, the site address `WX_SITE` derived from the base URL, the non-root port-binding sysctl note, and DP-1b's daemon duty (`"userland-proxy": false`, `ip6tables`, ULA subnet) with its `conntrack` check. Added Caddy's trusted proxy setting and `header_up X-Forwarded-For {client_ip}`, two upload limit settings (DP-1c), L sized at their maximum. Monitoring (old DP-12: one external monitor on `/api/health` and `/`, OQ-94) and OQ-93 (Caddy recreate outage) resolved by the user; AC references changed from 28–34 to the feature file's positions 1–9.
- **v0.4 (1 Nov 2026):** user decision (decision log 1 Nov 2026, Dockerfile). Added DP-16 (self-built image, `deploy/Dockerfile`, `compose.build.yaml`) and DP-17 (`make ci` builds it). DP-2 was "No image is built or pushed"; now the operator's deploy alone builds none and keeps the CI artefact. The feature file gained an AC at position 5, so AC references 5–9 became 6–10. Status line was "No open question of its own; INF-2 (report limit) stays open" (INF-2 was decided in v0.3's decision log entry).
- **v0.5 (2 Nov 2026):** user decision (decision log 2 Nov 2026, operator deploy from GitHub Releases). DP-2 and DP-10 had the operator deploy "the CI artefact of HEAD's green run" (uploaded on every push, 14-day retention, version = short commit hash, checked by prefix); now a GitHub Release built on a `vX.Y.Z` tag (DP-18), version = the tag, exact match. Status was "accepted (1 Nov 2026; OQ-95, OQ-96 decided by the user)". The feature file gained AC 1 (release on a green tag), so AC references 1–10 became 2–11. Requirements hand-off "the open point is settled (DP-2: the operator keeps the artefact path …)" done and replaced.
- **4 Nov 2026 (QA-30-r1-6, no version bump):** DP-8 ended "if not, apply ADR-017's "gate of 2" before buying RAM." The gate does not lower M(4); replaced by asking the user, and `regenerate` excluded from the cap (ADR-017 rev. 8).
