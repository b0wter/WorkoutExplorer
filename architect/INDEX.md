# Architecture index

Architecture documents and decisions for Workout Explorer, written by the senior-architect agent. Engineers read the documents for their feature, plus every accepted ADR they touch, before writing code. The spec in `../spec/` stays the source of truth for *what* the app does; these documents decide *how*.

Update this index whenever a document is added, changes status, or is superseded.

**History.** Live documents hold the current state only. Change logs, revision lists, finished engineer round lists, superseded and struck-through text, and decided question lists are in `architect/history/<same file name>` (for this index: [history/INDEX.md](history/INDEX.md), which also holds the earlier revision notes of the rows below and the Resolved rows that repeated product decisions). Read history only when you need it. Product decisions are in the decision log of `features/README.md`; this index does not repeat them.

## System-wide picture

The system-wide picture lives in `spec/Workout Explorer — Technical Design.md` (the TD): invariants I-1 to I-8, code structure (bounded contexts, repository layout, dependency rules), conventions and settings, glossary. `overview.md` was merged into it on 23 Oct 2026 and is a stub.
